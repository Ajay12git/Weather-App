## ⚡ Features

- Search for any city worldwide.  
- Displays current temperature, weather conditions, and an icon.  
- Auto-updates background based on weather conditions.  
- Simple, responsive, and lightweight — works on mobile and desktop.  
- Dark/light-friendly design (thanks to Tailwind CSS).  

---

## 🛠 Tech Stack

- **HTML5** – structure  
- **CSS3 & Tailwind** – styling & responsive design  
- **JavaScript** – interactivity  
- **OpenWeatherMap API** – live weather data
